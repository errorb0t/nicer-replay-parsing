To install this module:

`pip install git+https://github.com/errorb0t/nicer-replay-parsing.git`

This also installs a command-line tool that prints all decoded replay contents (like a functioning version of `heroprotocol` with all flags set):

`replaydump path/to/replay.StormReplay`
